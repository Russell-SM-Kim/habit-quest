# 게임 설계

> 목표: "66일 동안 습관을 끝까지 하게 만드는 것".
> 숫자는 전부 `core/game/.../rules/GameRules.kt` 한 파일에 있고, 바꾸면 과거 기록까지 새 규칙으로 다시 계산된다.

## 1. 시즌
- 한 시즌 = **66일** (습관 형성 연구에서 자주 인용되는 평균 기간).
- 66일이 끝나면 **시즌 2, 3 …이 자동으로 이어진다.** 레벨·스탯은 이어지고, 시즌 기록(획득 EXP, 완벽한 날 수)만 따로 남는다.
- 화면 표시: `Day 23 / 66`, `Season 1`, 남은 일수, 진행 막대.

## 2. 퀘스트
| 항목 | 내용 |
|---|---|
| 정의 | 이름, 난이도, 오르는 스탯(최대 2개, 70/30), 반복 요일, 목표량(분·km·회, 선택) |
| 매일 할 일 | **없음.** 요일에 맞는 퀘스트가 오늘 화면에 자동으로 뜨고, 탭해서 완료만 한다 |
| 택1 퀘스트 | 같은 그룹(예: 탁구 / 러닝) 중 하나만 하면 그 칸이 완료 |
| 승패 기록 | 탁구처럼 경기가 있는 운동은 이기면 AGI 스탯 경험치 ×1.5 |
| 보관 | 지운 퀘스트도 과거 기록은 남는다 (archivedOn 이후로만 안 나옴) |

난이도별 기본 EXP: 쉬움 10 · 보통 20 · 어려움 35 · 매우 어려움 60

### 기본 퀘스트 (첫 실행 시)
기상, 물 한 잔, 맨몸 근력(월수금), 탁구 or 러닝(화목토, 택1), 스트레칭(일), 독서 20분, 명상 10분, 취침 전 폰 금지.

## 3. EXP 계산
```
EXP = 기본(난이도)
    + 초과 달성 보너스  = 기본 × min((한 양 − 목표) / 목표, 1.0)       ← 최대 2배
    + 연속 보너스       = (기본 + 초과) × min(연속일 × 1%, 50%)
```
예) 독서 목표 20분, 실제 50분, 보통(20), 연속 10일
→ 초과 = 20 × min(30/20, 1) = 20, 연속 = 40 × 10% = 4 → **44 EXP**

- 완료 후에도 "기록 추가"로 양을 늘리면 다시 계산된다.
- 그날 예정 퀘스트를 전부 끝내면 **완벽한 하루 +30 EXP**.

## 4. 레벨 (끝없음)
- 레벨 L → L+1 필요 EXP = `60 + 40 × L` (상한 없음)

## 5. 스탯 6종과 "맞춤형" 자동 분배
| 코드 | 이름 | 주로 오르는 활동 |
|---|---|---|
| STR | 근력 | 맨몸 근력 운동 |
| END | 지구력 | 러닝 |
| AGI | 민첩 | 탁구 (승리 시 ×1.5) |
| INT | 지능 | 독서, 공부 |
| WIL | 정신력 | 기상, 명상, 폰 금지 |
| VIT | 활력 | 물, 스트레칭, 수면 |

남는 포인트를 직접 찍지 않는다. 레벨업하는 순간:
1. 모든 스탯 +1
2. 랭크 보너스 포인트(5~10)를 **이번 레벨 동안 실제로 한 활동의 스탯 비율대로** 나눠 준다 (최대 나머지 방식으로 정수 분배)
3. 활동 기록이 없으면 가장 낮은 스탯부터 채운다

→ 독서를 많이 하면 INT 가, 러닝을 많이 하면 END 가 자란다. 상태 화면에서 "다음 레벨업 예상 분배"를 미리 보여준다.

## 6. 랭크 (레벨 구간)
| 랭크 | 레벨 | 레벨업 보너스 | 칭호 |
|---|---|---|---|
| E | 1~ | 5 | 각성자 |
| D | 10~ | 6 | 수련생 |
| C | 20~ | 7 | 숙련자 |
| B | 35~ | 8 | 정예 |
| A | 50~ | 9 | 강자 |
| S | 70~ | 10 | 초월자 (이후 10레벨마다 S★1, S★2 …) |

## 7. 클래스
- **레벨 5 미만은 클래스 없음 (견습생).** 완전 초보에게 클래스를 붙이지 않는다.
- 그 뒤로는 가장 높은 스탯으로 결정: 전사(STR) · 러너(END) · 스트라이커(AGI) · 현자(INT) · 수도승(WIL) · 수호자(VIT)
- **올라운더**: 모든 스탯 30 이상 **그리고** 최고·최저 차이가 최고값의 15% 이내일 때만.

## 8. 꾸준함을 만드는 장치
| 장치 | 규칙 | 의도 |
|---|---|---|
| 연속 기록 | 그날 예정 퀘스트의 **80% 이상** 완료하면 이어짐 | 100% 강요하지 않기 |
| 보호권 | 연속 7일마다 1장 (최대 2장), 놓친 날 자동 사용 | 하루 실수로 무너지지 않게 |
| 회복 퀘스트 | 연속이 끊긴 **다음 날** 스쿼트 50회 + 명상 10분 하면 복구 | 포기 대신 만회 |
| 주간 보스 | 월요일 등장, 운동 퀘스트 1회 = 데미지 1, 처치 시 +60 EXP | 운동 동기 |
| 근력 프로그램 | 주차에 따라 푸시업·스쿼트·플랭크·런지 횟수 자동 증가 | 점진적 과부하 |
| 마일스톤 | 7일·21일·30일·66일 | 중간 목표 |
| 연출 + 효과음 | 클리어 토스트, 레벨업·랭크업·전직·보스 처치 창 | 즉각적인 보상감 |

## 9. 저장하지 않는 것
레벨·EXP·스탯·클래스·연속기록은 **저장하지 않는다.** 저장하는 것은 "언제 어떤 퀘스트를 얼마나 했는지"뿐이고,
나머지는 `GameEngine` 이 시작일부터 기록을 다시 재생해 계산한다. → 자세한 이유는 [architecture.md 의 ADR-2](architecture.md)
