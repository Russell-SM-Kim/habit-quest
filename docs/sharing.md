# 다른 사람과 같이 쓰기

친구가 앱을 설치해서 **자기 Google 계정으로 로그인**하고, 기록이 **내 PC 서버에 계정별로** 저장되게 하는 방법.
코드는 이미 준비돼 있고, 아래 설정만 하면 된다.

```
친구 폰 (앱) ──HTTPS──▶ 내 PC (Tailscale) ──▶ 서버 ──▶ PostgreSQL
             Google 로그인 → 친구 계정의 기록만 읽고 씀
```

## 1. 앱에 서버 주소 넣기 (친구가 주소를 입력하지 않게)
프로젝트 루트의 `local.properties` (git 에 안 올라감) 에 한 줄 추가:
```
habitquest.serverUrl=https://내PC이름.tailnet이름.ts.net
```
Sync 후 빌드하면 시작 화면에서 바로 "Google 계정으로 시작하기" 만 누르면 된다.
(비워 두면 시작 화면에 주소 입력칸이 나온다)

## 2. 친구가 서버에 닿게 하기 (둘 중 하나)

| | A. 내 PC 만 공유 (추천) | B. 인터넷에 공개 (Funnel) |
|---|---|---|
| 방법 | Tailscale 관리 화면 → Machines → 이 PC `…` → **Share** → 친구 이메일 초대 | 관리자 cmd: `tailscale funnel --bg 8080` (처음엔 Funnel 허용 링크가 나오니 눌러서 켠다) |
| 친구가 할 일 | Tailscale 설치 → 초대 수락 → 켜 두기 | 앱만 설치 |
| 노출 | 초대한 사람만 접근 | 주소를 아는 누구나 접근 (로그인·허용 목록이 막음) |

B 를 쓰면 서버의 `/auth/google` 에 **IP 당 분당 20회** 속도 제한이 걸려 있다.

## 3. 누가 로그인할 수 있나
두 곳을 모두 통과해야 한다.

1. **Google Cloud → Google 인증 플랫폼 → 대상**
   - 테스트 상태: **테스트 사용자**에 넣은 계정만 (최대 100명)
   - 더 많은 사람 / 매번 추가하기 귀찮으면: **앱 게시 → 프로덕션**.
     이 앱은 기본 범위(이메일·프로필)만 쓰므로 별도 심사 없이 게시할 수 있다.
2. **서버 `start-server.bat` 의 `LIFE_RESET_ALLOWED_EMAILS`**
   - 쉼표로 이메일 나열 → 그 계정만
   - 비우면 Google 계정이면 누구나 (서버 시작 시 경고 로그)
   - 바꾼 뒤에는 **서버를 다시 켜야** 적용된다

## 4. 앱 전달
Android Studio → Build → Build APK(s) → `app/build/outputs/apk/debug/app-debug.apk`.
내 PC 에서 빌드한 APK 라야 Google 에 등록한 SHA-1 과 서명이 같아서 로그인이 된다.

## 동기화는 언제 되나
| 언제 | |
|---|---|
| 앱을 열 때 | 바로 |
| 퀘스트를 완료·수정했을 때 | 5초 뒤 (연달아 하면 마지막 한 번) |
| 앱을 안 열어도 | 15분마다 |
| 인터넷이 끊겼을 때 | 폰에 저장해 두고, 연결되면 자동으로 |

오늘 화면 위쪽에 `동기화 3분 전` / `동기화 실패` 가 표시된다.

## 알아둘 것
- 내 PC 가 꺼져 있으면 모두 동기화가 멈춘다 (기록은 각자 폰에 남아 있다가 나중에 올라감).
- 친구들 기록도 내 DB 와 백업에 저장된다.
